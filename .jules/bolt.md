## 2024-06-26 - [jq Array Mapping & TSV Performance Pattern]
**Learning:** Calling `jq` multiple times on the same JSON payload in subshells creates measurable performance overhead in bash scripts. This can be solved by batching multiple queries into a single `jq` array mapping and piping it out via `@tsv`. However, if the API response is unexpectedly null or missing a field, `jq` error handling can become strict resulting in `Cannot iterate over null` failures.
**Action:** When creating batched `jq` TSV mappings, explicitly make all access optional by using the `?` suffix on iterators (e.g. `.sessions[]?` or `.sessions?`) and properly test JSON property presence (e.g., `select(.title and (.title | test("...")))`) to gracefully evaluate to false without breaking iteration over the batched array length.
