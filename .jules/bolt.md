## 2024-08-01 - Optimizing Bash Pipeline Tests
**Learning:** Using sequential `jq` and `bc` subprocess calls inside a bash test script can add significant overhead due to shell forking. Specifically, parsing the same JSON payload multiple times with `jq` in the agentic-skills test suite (e.g. counting agent types and status) creates an unnecessary bottleneck. In bash `jq` `@tsv` arrays, `// empty` will strip null elements and misalign `read -r` position assignments, so using the null coalescing `// []` alongside `?` ensures empty/null sets safely evaluate to `0` instead of breaking variables.
**Action:** Always batch JSON processing into a single `jq` invocation using `@tsv` output read directly into multiple bash variables via `IFS=$'\t' read -r`. Rely on native shell arithmetic (`$(( ))`) instead of external `bc` calls for integer math, and use `awk` for format scaling.
