## 2024-05-14 - jq process spawning overhead in bash test scripts
**Learning:** In bash test scripts like `tests/run_all.sh`, repeatedly spawning `jq` processes inside a pipeline run or loop creates significant process overhead. When testing large JSON arrays, using multiple individual `jq` queries (e.g., to count different filters) is a major performance bottleneck. Additionally, executing external processes like `bc` for simple arithmetic inside loops exacerbates the slowdown.
**Action:** When extracting multiple values or counts from the same JSON string in bash, batch all queries into a single `jq` array output formatted with `@tsv`. Use `map(. // 0)` to handle null values gracefully, and assign them directly to bash variables using `IFS=$'\t' read -r ... <<< "$(echo "$var" | jq -r '...')"`. For simple math operations, avoid `bc` and use native bash integer arithmetic (`$(( ))`) or `awk`.
