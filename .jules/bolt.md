## 2024-07-17 - Batching jq queries in bash
**Learning:** Making multiple subshell calls to `jq` on the same JSON payload in bash is a significant performance bottleneck (creating ~75% overhead). When looping or extracting multiple fields, `jq` supports batching outputs into an array and formatting as TSV (`@tsv`). Furthermore, when evaluating against possible null payloads (e.g. mock API responses without a `.sessions` array), we must use the `?` operator (like `.sessions[]?`) to prevent "Cannot iterate over null" errors. Similarly, using `test()` on a null field like `.title` throws a fatal error, so it must be guarded like `select(.title and (.title | test("...")))`.
**Action:** When extracting multiple values from a JSON string in a bash script, combine them into a single `jq` call that outputs a TSV array and use `IFS=$'\t' read -r var1 var2 <<< "$(echo "$json" | jq -r '... @tsv')"`. Always use `?` for array iteration over potentially missing fields and check for null before using `test()`.
