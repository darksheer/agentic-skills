## 2024-05-15 - Batched jq processing
**Learning:** jq arrays break empty elements like `// empty` dropping from the resulting output. This mismatch breaks array assignment with bash arrays logic (e.g. `IFS=$'\t' read -r ...`). Also jq crashes when evaluating null fields in `.sessions[]`.
**Action:** Use conditional assignment and placeholder default arrays like `(.sessions // [])` in jq instead. Handle missing or optional null objects safely with `?` like `.sessions[]?` to avoid crashing bash scripts when mock responses are evaluated. Avoid empty array elements for positional `read -r` assignments. Replace multiple `jq` calls within the same JSON by selecting all the variables into an array and mapping it through `@tsv` to be read via bash `read` to reduce the number of shells executed and decrease overall runtime.
