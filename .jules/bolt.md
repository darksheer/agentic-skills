## 2024-05-15 - Fast arithmetic in bash tests and safe jq array indexing
**Learning:** Found two performance-related issues specific to the `run_all.sh` test suite. Firstly, math calculations were done using `$(echo "$score + X" | bc)` which is extremely slow because it forks subshells and the `bc` process multiple times per evaluation (approx ~1.16s for 100 runs vs ~0.4s natively). Secondly, when fetching sessions with a mock API key, the API returns a JSON error without a `.sessions` array, causing `jq` array operations without the `?` optional or default `// []` operator to crash the script with "Cannot iterate over null".
**Action:** Replace `bc` arithmetic with native bash integer math `$((score + X))` and use `awk` for floating-point calculation if needed. When processing `jq` queries on `.sessions` in bash, ensure `.sessions` is safely accessed (e.g. `(.sessions // []) | length` or `[.sessions[]?]`) to gracefully handle null outputs and prevent test crashes.
