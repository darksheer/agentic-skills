## 2024-05-19 - Bash IFS Whitespace Compression Breaking TSV Assignment
**Learning:** When using `IFS=$'\t'` to read tab-separated values from a batched `jq` query in bash, bash will treat consecutive whitespace delimiters (including multiple tabs) as a single delimiter. If a field like `.title` is empty and outputs `""` (resulting in `\t\t` in the TSV stream), bash will collapse the tabs, dropping the empty field entirely, which incorrectly shifts all subsequent variables leftward during the `read -r` assignment.
**Action:** When extracting multiple variables from `jq` into bash using `read`, either use a non-whitespace delimiter (`IFS='|'` and `. | join("|")`) or ensure fallback values are never truly empty (e.g., `// "null"`) to preserve positional assignment integrity.
